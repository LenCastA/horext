Este repositorio centraliza y documenta el ecosistema de componentes de **Horext** en este fork.

### 📌 Características Principales
- **Generación Automática de Horarios**: Optimización y simulación de combinaciones de cursos para estudiantes de la Universidad Nacional de Ingeniería (UNI).
- **Múltiples Cargas Horarias**: Soporte para versiones preliminares y oficiales por periodo académico.
- **Zona Horaria Perú (`America/Lima`)**: Formateo y publicación sincronizada con la hora local de Lima.
